# 오늘 충남 — 팀원용 앱 테스트 체크리스트

개발 도구 없이 앱을 사용하며 확인하는 목록입니다. 한 사람당 약 30~45분을 잡고, 전부 못 하면 확인한 항목만 제출해 주세요. 아래 체크박스는 **실제로 해 보고 정상일 때만** 체크합니다. 실패·못 해 봄은 결과 양식에 따로 적습니다.

## 시작 전에

- 담당자가 전달한 **같은 버전의 앱**을 사용하고 앱 버전/빌드 이름을 기록합니다.
- 현재 개발 버전은 개발 PC의 서버와 연결되어야 합니다. 지금 연결된 시험용 휴대폰은 USB 연결을 사용합니다. **APK만 다른 휴대폰에 설치하면 바로 서버에 연결되는 상태는 아닙니다.** 다른 기기에서는 담당자에게 접속 설정을 받은 뒤 시작하세요.
- API 키를 공유받거나 직접 입력할 필요가 없습니다. 연결이 안 되면 담당자에게 알립니다.
- 기존에 저장해 둔 장소는 지우지 않습니다. 테스트 중 새로 저장한 장소만 마지막에 정리합니다.
- 화면을 찍을 때 알림·개인정보는 가립니다. 비밀번호나 API 키를 보내지 않습니다.

작성자: ______ / 날짜: ______ / 기종·OS: ______ / 앱 버전: ______

## 1. 누구나 먼저 해 보기

추천은 **‘스팟 추천’ = 장소 목록**, **‘코스 추천’ = 정해진 순서로 방문할 장소 묶음**입니다.

- [ ] **T01** 앱을 켜면 홈 화면이 나오고 ‘스팟 추천’, ‘코스 추천’, ‘저장’에 들어갈 수 있다.
- [ ] **T02** 스팟 추천에서 `천안 → 대중교통 → 천안역`을 고르고 다음 단계로 이동한다.
- [ ] **T03** ‘누구와’를 고르지 않고 추천하면 선택하라는 안내가 나온다. 선택 후에는 진행된다.
- [ ] **T04** `친구와 + 카페 투어`로 추천을 받는다. 이름·주소·분류가 읽히고 버튼이 눌린다.
- [ ] **T05** 요청한 장소 수와 결과 수가 맞는다. 적게 나왔다면 부족하다는 설명이 있다.
- [ ] **T06** 결과 중 장소 하나를 저장하면 ‘저장’ 탭에 같은 장소가 나타난다.
- [ ] **T07** 앱을 닫았다 다시 열어도 저장한 장소가 남는다. 앱 삭제/데이터 초기화는 하지 않는다.
- [ ] **T08** 저장 삭제에서 ‘취소’를 누르면 남아 있고, 테스트로 만든 항목을 삭제하면 그 항목만 없어진다.

## 2. AI가 내 말을 제대로 이해하는지

이 기능은 입력 문장을 선택 태그로 바꿉니다. 태그를 잘 뽑는 것과 장소가 실제 취향에 맞는 것은 별도로 평가합니다.

- [ ] **T09** `친구와 조용한 카페에서 쉬고 싶어요`를 넣고 AI 태그를 실행한다. 동행·분위기·활동이 문장과 맞는지 적는다.
- [ ] **T10** `카페 말고 부모님과 실내 전시를 보고 싶어요`를 넣는다. 원하지 않은 카페가 주된 활동으로 선택되거나 추천되는지 확인한다.
- [ ] **T11** 입력을 비우고 AI 버튼을 누르면 안내가 나온다. 화면이 멈추지 않는다.
- [ ] **T12** AI 결과에서 태그를 직접 바꿀 수 있다. ‘누구와’는 한 개, ‘분위기’는 여러 개를 고를 수 있다.

AI가 이상하게 골랐다면 **입력 문장과 실제 선택된 태그**를 함께 남겨 주세요. 같은 문장을 여러 번 반복 호출할 필요는 없습니다.

## 3. 코스 순서와 중복 장소

- [ ] **T13** `음식 → 자연·산책 → 카페` 순서로 코스를 요청한다. 실제 결과의 분류와 순서가 맞는다.
- [ ] **T14** 코스의 장소 수를 3/4/5 중 두 가지로 바꿔 본다. 화면에 표시된 장소 수가 선택과 맞는다.
- [ ] **T15** 코스 안에서 **같은 실제 장소를 두 번 방문하게 만들지 않는다.** 이름이 조금 달라도 주소·지도 위치가 같은지 살핀다.
- [ ] **T16** 코스 여러 개를 요청하고 좌우로 넘겨 본다. 페이지 번호와 내용이 맞고, 선택한 페이지의 코스가 저장된다.
- [ ] **T17** 저장한 코스를 열면 장소 순서와 주소가 원래 결과와 같다.
- [ ] **T18** ‘거리’ 설명이 실제 운전·대중교통 소요 시간으로 오해되지 않는지 확인한다.

**중복 판단 주의:** 다른 코스에 같은 장소가 일부 포함되거나 같은 조건으로 다시 추천했을 때 같은 장소가 나오는 것 자체는 오류가 아닙니다. 다만 여러 코스가 사실상 똑같아 선택지가 없으면 ‘다양성 부족’으로 기록하세요. 이름이 같은 다른 지점은 서로 다른 장소일 수 있습니다.

## 4. 실제 장소와 비교하기 — 가장 중요

각자 추천된 장소 **5곳**을 골라 확인해 주세요. 지도에서 찾기 쉬운 곳만 고르지 말고, 가능하면 서로 다른 종류를 섞습니다. 방문하지 않아도 확인할 수 있는 정보부터 비교합니다.

- [ ] **T19** 앱의 지도 버튼이 해당 장소를 연다. 같은 이름의 다른 도시·지점으로 연결되지 않는다.
- [ ] **T20** 앱의 이름·주소와 지도 또는 해당 시설의 공식 안내가 일치한다.
- [ ] **T21** 분류가 실제와 맞는다. 예: 카페를 요청했는데 단순 사무실이나 전혀 다른 업종이 아닌지.
- [ ] **T22** 실제로 확인 가능한 이전·폐업 정보가 있다면 기록한다. 검색에 안 나온다는 이유만으로 폐업이라고 단정하지 않는다.
- [ ] **T23** 내가 요청한 활동에 적합한지 평가한다. ‘조용함’, ‘분위기’처럼 직접 확인 못 한 특성은 ‘모름’으로 표시한다.
- [ ] **T24** 지도에서 돌아왔을 때 추천/저장 화면을 계속 사용할 수 있다.

| 장소 이름·앱 주소 | 내가 요청한 조건 | 이름·주소 일치 O/X/? | 업종·활동 일치 O/X/? | 이전·폐업 등 확인 내용 | 확인 출처 링크·날짜 |
|---|---|---|---|---|---|
| 1. | | | | | |
| 2. | | | | | |
| 3. | | | | | |
| 4. | | | | | |
| 5. | | | | | |

`?`는 확인 불가입니다. 예를 들어 5곳 중 3곳 일치, 1곳 불일치, 1곳 확인 불가라면 **3/4 확인 가능 표본 일치, 1/5 미확인**으로 보고합니다. 이를 전체 장소 정확도라고 말하지 않습니다.

## 5. 불편하거나 막히는 상황

- [ ] **T25** 위치 권한을 거부해도 천안/아산을 직접 골라 추천받을 수 있다. 설정을 바꿨으면 원래대로 되돌린다.
- [ ] **T26** 천안에서 아산으로 바꾸면 출발지와 결과가 새 조건을 따른다.
- [ ] **T27** 요청 중 뒤로 가거나 잠시 다른 화면으로 갔다 돌아와도 멈추거나 이상한 화면으로 이동하지 않는다.
- [ ] **T28** 빠르게 추천·저장 버튼을 두 번 눌러도 같은 항목이 중복 저장되거나 화면이 겹치지 않는다.
- [ ] **T29** 키보드가 떠 있거나 글이 길어도 다음/추천/저장 버튼을 사용할 수 있다.
- [ ] **T30** 오류가 발생하면 이유를 알 수 있고 다시 시도할 수 있다. 통신 끊김을 일부러 만드는 검사는 담당자가 진행한다.

## 팀원끼리 역할 나누기

모두 1번 기본 흐름은 해 보고, 아래처럼 강조 항목을 나누면 좋습니다. 기기는 한 번에 한 사람이 조작합니다.

| 담당 | 중점 |
|---|---|
| A | 천안·대중교통·스팟, 카페/음식 실제 정보 5곳 |
| B | 아산·자동차·코스, 자연/문화 장소 5곳과 방문 순서 |
| C | AI 문장·부정 표현·조건 변경, 활동 일치 5곳 |
| D | 저장·재실행·지도·화면/권한, 동명 지점 구분 5곳 |

3명이라면 D를 나눠 맡으면 됩니다. 서로 일부 같은 조건도 써 보면 특정 기기에서만 생기는 문제를 찾을 수 있습니다.

## 문제 제보 — 이 양식만 복사해도 됩니다

```text
작성자 / 기기 / 앱 버전:
항목 번호: 예) T15
선택한 조건: 지역 / 출발지 / 교통 / 동행 / 활동 / 입력 문장 / 개수
어떻게 했나요? 1. ... 2. ... 3. ...
기대한 결과:
실제 결과:
장소 이름·주소 또는 코스 순서:
다시 했을 때: 1회만 발생 / 2번 중 2번 / 확인 못 함
사진·영상 또는 확인 출처:
사용을 계속할 수 있나요? 예 / 아니오
```

최종 제출: `확인한 번호 / 실패한 번호 / 못 해 본 번호 / 실제 장소 비교 5곳 / 가장 불편했던 점 1~3개`.

## 현재 알고 있는 제한

- 지금 DB에는 검증된 블로그 취향 태그가 없습니다. 카테고리·인기도·거리로 추천한다는 안내가 보여야 합니다. **취향 정확도가 검증된 서비스라고 평가하지 않습니다.**
- 현재 거리 표시는 실제 교통시간이나 영업시간 보장이 아닙니다.
- 현장 분위기·혼잡도·접근성은 실제 방문 확인 전에는 미확인입니다. 지도 정보도 최신이 아닐 수 있으므로 출처와 확인 날짜를 남깁니다.
