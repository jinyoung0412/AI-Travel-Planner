# 2026-10-28 AI 후보 비교 시간 초과·지도 버튼 후속 수정

사용자 요청: AI 후보 비교 시간 초과 원인 수정, 한국어 재검사, 노션 기록. 노란 카카오맵 버튼의 과도한 강조 조정. 대표 이미지 진행 상태 재확인.

## 원인과 변경

기존 선택 단계는 8초 제공자 응답 제한(호출자 최대 9초) 안에 긴 장소 해시, 근거 ID, 미확인 조건 배열을 선택한 모든 방문마다 복사하도록 요구했고 출력 상한은 5,500토큰이었다. 이전 실제 공방/코스 추천은8.47초/8.62초 후 provider_timeout으로 대체 추천됐다. 통신 장애만으로 단정할 근거는 없었고, 불필요한 생성량을 줄인 후 같은 모델·같은8초 제한에서 아래6회가 모두 완료됐다.

첫 수정은 후보별 번호만 반환해 시간을 약1초로 줄였다. 그러나 AI가 재조합한 결과의 최근 이력 중복/코스 품질 검사가 작동해6회 중 5회가 대체 추천으로 전환됐다. 원시 결과(index-transport-*)를 보존했다. 서버만 알고 있는 품질·다양성 기준을 모델이 번호만 보고 재현할 수 없다는 추가 문제를 확인했다.

최종 구조는 서버가 검증한 장소 집합·코스를 AI가 비교해 순위만 결정한다. 요청은 실제 추천안의 이름·종류·직선거리만 담으며 전체 30후보와 긴 근거 ID를 보내지 않는다. 반환은 {order:[...]}이며 모든 추천안 번호가 정확히 한 번씩 있어야 한다. 서버는 원래 장소·근거·미확인 조건을 복원하고 기존 최종 거리/종류/중복/다양성/최근 이력 검사를 유지한다. 모델이 새 장소를 생성하거나 방문을 교체하지 않는다. 기초 장소 선정은 서버, 최종 정렬은 AI임을 metadata.selection_scope=rank_validated_recommendations로 명시했다. 제한시간과 재시도0 정책은 늘리지 않았으며 출력 상한은 512토큰이다. 잘못된 모델 응답이나 제공자 장애 시 기본 추천 복구도 유지했다.

최대 30후보의 합성 계약 표본에서 10곳 응답은 4,073→31바이트, 3단계3코스 응답은3,655→17바이트다. 실제 과금 토큰 측정이 아닌 전송 형식 비교이며 transport-size.json에 분리했다. 중간 순위 형식에서도 후보 번호/추천안 번호 혼동을 발견해 입력에 추천안 번호만 제공하도록 정리했다(rank-initial-* 및 spot-diagnostic 기록 보존).

## 실제 한국어 재검증

## 지도 버튼 및 휴대폰

쨍한 노란 바탕을 연한 크림색(#FFF3EC), 브라운 글자(#914B33), 얇은 테두리(#E7D1C4)로 변경했다. 48dp 이상 터치 영역·지도 아이콘·열기 중 표시·중복 클릭 방지는 유지한다. 공통 버튼을 사용하므로 스팟·코스·저장 화면에 적용된다.

DEVICE_ID에 업데이트 설치했고 설치 APK 해시는 5a022edc9e7f4f3261d7a0925ad5b977bf553fb81b2248aa7e65e9e32b431264로 빌드와 일치했다. 삭제/초기화 없음. 삼성 한글 키보드로 ‘여자친구랑100일기념데이트’를 띄어쓰기 포함 실제 입력하고 태그 선택→체험·만들기→추천 완료, 새 버튼 색상을 실기기에서 확인했다. 이번 외부 지도앱의 목적지 일치 검사까지 수행한 것은 아니다.

자동 검사: 최종 Python 1,131개 통과, 관련 173개 통과(전체에 포함), 지도 버튼 Flutter 24개 통과, Flutter analyze 이상 없음. DB·고정pilot 불변. 최신 휴대폰 연결은 8080→8082→Flask5004. 이전 서버는 유지하며 로컬 서버 종료 시 연결도 종료된다.

## 대표 이미지 상태

아직 앱에 적용하지 않았다. 현재 places 테이블 20필드 중 사진/이미지URL/contentID 필드 0개다. TourAPI는 관광정보·사진을 공식 제공하며 공공누리 1·3유형에 맞는 출처/이용조건 처리가 필요하다. 공식 관광공사 자료에서 현충사(아산 이충무공 유허), 독립기념관 자료는 확인했으나 이번 공방인 어썸소잉하우스/노드랩의 대응 자료는 검색으로 확인하지 못했다. 검색 미발견은 API에 없다는 증명이 아니며 API 표본 조회/매칭률 측정은 수행하지 않았다. TourAPI 활용 승인과 별도 키, 장소 이름·주소·좌표 매칭 검증 후 확인된 장소만 사진을 보여주고 미매칭은 현재 텍스트 카드를 유지하는 방향을 권장한다. 기존 Anthropic 키로 TourAPI를 호출할 수는 없다.

## 마지막 재추천 UX 회귀 수정

실기기에서 자연어 추천 뒤 ‘같은 조건으로 새 추천’을 누르면 선택한 활동을 다시 묻는 것을 발견했다. 성공한 결과의 활동 선택만 재추천 요청에 이어받도록 수정했다. 새 seed와 새 해석 서명은 발급받고, 새 질문의 허용 선택지에 이전 활동이 있을 때만 자동 적용한다. 미확인 조건에 대한 승인은 다시 받으며, 조건 수정 후 일반 요청에는 활동을 자동 적용하지 않는다. 관련 22개 검사와 최종 Flutter 전체 272개가 통과했다. 기존 색상 테스트가 노란색을 고정 기대해 1회 실패했고, 사용자 변경 요구에 맞춰 4.5:1 이상의 글자 대비 검사로 바꾼 후 전체를 다시 통과했다. 실패 로그는 보존했다.

최종 실기기 확인: 새 APK에서 한국어 기념일 체험 추천 후 같은 조건으로 새 추천을 누르자 활동 재질문 없이 새 공방 결과로 넘어갔다. 설치 해시 일치와 Notion 추가 기록 저장·읽기 확인 완료. 근거: installation-final.json, notion-final-readback.txt, device/final-reroll-complete.xml 및 화면.
